# Pulse: Recreated
This projects attempts to implement the Pulse site from scratch using React, Vite, Typescript and Tailwind CSS. Instead of aiming for 1:1 pixel-perfect recreation, the goal is to put the authors frontend skills to the test.

The author of this project is not affiliated with Pulse. For the official site, please visit [pulseapp.com](https://pulseapp.com/)
